# Audit of the pre-`research-grade` code base

Audited commit: `c8bab2f` (branch `enhancement_changes`). Line numbers refer to that commit.
Every finding has a regression test in `tests/audit/`; the test file is named in the last column.

| # | Finding | Evidence (file:line @ c8bab2f) | Fix | Status / test |
|---|---|---|---|---|
| A1 | **Oracle leakage.** Ground-truth labels drive trust updates, the agent's reward, and even the agent's *observation*. | `src/simulation/simulation_manager.py:440-446` (every 15 steps, true malicious nodes get `update_trust(...,"malicious")` with p=0.7, true honest nodes get `"valid"`); `:455-462` reward from `calculate_shaped_rewards(..., true_malicious_nodes, true_honest_nodes)` and an FN penalty computed from true labels; `:270` state feature `detect_collusion(self.trust_manager, self.true_malicious_nodes)`; `:222` ABAC attributes assigned from ground truth (malicious => `user_role`); `src/rewards/reward.py:28-36,49-66` reward is a function of the true honest/malicious trust gap. | Old simulation loop removed. New `src/env/honest_env.py` keeps ground truth in a private `_World`; decision components get an `Observation` without labels; trust is updated only from audit evidence; rewards use audited agreement, latency and audit cost (`src/env/rewards.py`). Ground truth is read only by `src/metrics/ground_truth_metrics.py`. The old reward module is deleted. | Fixed — `tests/audit/test_a1_no_oracle.py`, `tests/audit/test_no_ground_truth_access.py` |
| A2 | **Votes are a function of trust**, so "consensus quality" is circular: high-trust delegates always vote correctly, low-trust delegates always vote wrong, the rest vote by salted hash. | `src/consensus/tdcb.py:56-63` | Votes now come from the vote model in `src/env/honest_env.py`: honest delegates vote on a noisy observation of validity (`honest_fault_rate`), malicious delegates follow their attack policy. | A3 | **Attacks write trust state directly** (`adjust_trust`, `update_trust`, direct `alpha`/`beta` edits): 52 direct writes across the attack modules. | `src/attacks/aaa_attack.py:130-186` (21 writes), `tdp_attack.py` (12), `bfi_attack.py`, `cra_attack.py`, `nma_attack.py` (5 each), `attack_util.py` (4) | Old attack modules deleted. `src/env/attacks.py` implements NMA, CRA, AAA, BFI, TDP as vote/timing policies; they receive no handle to the trust backend. | Fixed — `tests/audit/test_a3_attacks_vote_only.py` |
| A4 | **Dead action knobs.** The 27-action map sets `TRUST_DECAY_RATE` and `CONSENSUS_THRESHOLD` in the global `parameters` module; neither is read by any decision code (only logged). | A6 | Consensus threshold hard-coded to 0.667; Python `hash()` (salted per process via `PYTHONHASHSEED`) used for votes, so runs were not reproducible across processes. | `src/consensus/tdcb.py:90` (threshold), `:63` (`hash(delegate + tx_hash)`) | `theta` is a `RunConfig` field; hashing uses `hashlib.blake2b`. Bit-identical reruns tested across two subprocesses with different `PYTHONHASHSEED`. | Fixed — `tests/audit/test_a6_threshold_and_hash.py` |
| A7 | `classification_report(..., zero_division=1)` reports precision = 1 when nothing is flagged, inflating F1. | `src/simulation/simulation_manager.py:726-728` | `src/metrics/ground_truth_metrics.py` uses `zero_division=0` and reports precision, recall, F1 and MCC separately. | Fixed — `tests/audit/test_a7_zero_division.py` |
| A8 | No train/test split and no episode reset: the agent is evaluated on its own training stream (state carried across episodes via `self.last_state`, trust/attack singletons never reset). | `src/simulation/simulation_manager.py:382, 520`; attack singletons `src/attacks/attack_util.py:15` | Episode = one `HonestEnv(seed, cfg)` from scratch. | A10 | Duplicate, diverged modules: root `api/` vs `src/api/`, root `baselines/` vs `src/baselines/`, ~15 root shims (`abac.py`, `trust.py`, ...), `experiments/_generate_paper_figures_impl.py` vs root `generate_paper_figures.py`; commented-out duplicate classes in `src/agents/marl_agent.py:14-230`. | `diff -rq api src/api` shows all files differ | One canonical module per concept under `src/`.
